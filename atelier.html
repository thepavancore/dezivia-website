FAQS

A FEW THINGS
YOU MAY ASK.

What do you need to start a project?

CAD drawings, 3D models where available, sketches, reference images, material information and a project brief. Requirements vary depending on the service.

Do I need to provide a 3D model?

No. If a suitable model is not available, 3D modelling can be included as part of the project scope.

How long does a visualisation take?

Timelines depend on project size, complexity, number of views and revision requirements. A timeline is discussed before production begins.

How many revisions are included?

The number of revision rounds is clearly defined in the quotation based on the agreed scope.

Can you work with projects outside India?

Yes. Dezivia Atelier works remotely and collaborates with architects, designers, studios and clients internationally.

What file formats can you work with?

We can work with common architectural drawings, 3D models and reference formats. Specific requirements can be discussed before the project begins.

Can you create animations as well as still images?

Yes. Depending on the project, Dezivia can create architectural walkthroughs, cinematic animations and short-form presentation content.
